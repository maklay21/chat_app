# План работы

Разработать чат для одного юзера с возможностью отправки сообщений, вывода всех сообщений в чате
Бэкэнд: Использование любого API фреймворка, SQL база данных не нужна, поэтому можно взять Редис для быстрого кэширования данных в ОЗУ
Фронтенд: React с CSS стилистикой

Для начала нужно написать два эндпоинта апи - отправка сообщений, и вывод всех сообщений
Далее необходимо написать интерфейсы React для взаимодействия с апи, а также красиво оформить полученные данные
Для деплоя использую docker compose
